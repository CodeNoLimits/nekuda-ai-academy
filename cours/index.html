Claude, Claude Code, Artefacts & Automations (50 min) Activer les Artefacts dans Claude pour créer instantanément des maquettes de pages, des nuanciers d'imprimerie et des calculateurs de prix. Introduction à Claude Code. הפעלת Artifacts ב-Claude ליצירה מיידית של דפי נחיתה, מניפות צבעים לדפוס ומחשבוני הצעות מחיר. היכרות ראשונה עם Claude Code.

Utiliser Grok comme assistant ultra-rapide et GrokBot pour exécuter des tâches directes. הצצה ל-Antigravity (תיאום בין מספר סוכני AI במקביל). שימוש ב-Grok כעובד מהיר במיוחד וב-GrokBot למשימות מיידיות.
  • 4. Gemini / Grok Imagine pour Images & Vidéos (45 min) Générer 10 visuels de haute précision (textures papier, dorure à chaud, packagings cosmétiques/alimentaires, décors Bat Yam) et les animer en vidéo. יצירת 10 תמונות ברמת סטודיו (טקסטורות נייר, השבחות פויל זהב, אריזות ממותגות ונופי בת ים) והנפשתן לווידאו.

Plan de travail & Fonction Devis Automatiqueתוכנית עבודה ופונקציית הצעת מחיר אוטומטית

  • 1. Setup Complet de l'Ordinateur (45 min) Installation de Claude Code, Git, GitHub et Vercel sur chaque poste de travail du studio à Bat Yam. התקנת Claude Code, חיבור ל-GitHub ו-Vercel והגדרת תיקיות העבודה על כל מחשב בסטודיו.

  • 3. Fonctions de Code pour Générer des Documents en Automatique (45 min) Création du générateur automatique de devis PDF (הצעות מחיר), bons d'impression et catalogues clients. בניית פונקציית קוד שמייצרת אוטומטית הצעות מחיר ב-PDF, הזמנות עבודה וקטלוגים ממותגים.
  • 4. Connexion Réseaux Sociaux & Auto-Post (45 min) Relier Instagram, TikTok, Facebook et YouTube Shorts pour planifier et publier les créations automatiquement. חיבור הרשתות החברתיות (אינסטגרם, פייסבוק, טיקטוק, יוטיוב) לתזמון ופרסום אוטומטי של התוכן. 
// Exemple de fonction générée avec Claude Code en Séance 3 :
function generateNekudaQuote({ client, product, quantity, finish, unitPriceILS }) {
  const subtotal = quantity * unitPriceILS;
  const vat = Math.round(subtotal * 0.18); // מע"מ 18%
  const total = subtotal + vat;
  return {
    studio: "דפוס נקודה · nekudap.co.il · 03-6814430",
    client, product, quantity, finish,
    subtotalILS: `${subtotal} ₪`,
    vatILS: `${vat} ₪`,
    totalILS: `${total} ₪`,
    status: "READY_FOR_PDF_AND_WHATSAPP"
  };
}
